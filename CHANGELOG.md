# Changelog

All notable changes are recorded here. LumaSave follows semantic versioning;
pre-release builds may still change configuration and D-Bus details.

## 0.1.0-alpha.1 — unreleased

- Native KWin effect with content-adaptive physical backlight reduction.
- Full-desktop SDR compensation that preserves exact black.
- On, After inactivity, Off, battery-only, and inhibited-playback policies.
- System Settings module, real-display calibration, and Plasma status widget.
- Full-scale saved-backlight accounting based on brightness × reduction × time.
- HDR activation guard and runtime fail-safe.
- Rootless source installer and Arch package.
